# Goulds--Flood-risk-assessment

This project aims to investigate the relationship between discharge, precipitation, and gage height, and assess whether increases in discharge and precipitation are associated with higher water levels and potential flood conditions in the Goulds community, Florida, USA, between 2020 and 2026.

A Neural Network and a Random Forest model were used to forecast gage height one hour ahead. The performance of the two models was compared to determine which model provided more accurate predictions.

Also, the project aimed to identify potential high-water conditions using a gage height threshold. As no formal or publicly available gage height threshold for flooding at the study location was identified, the 95th percentile of the training-period gage height data was used as a statistical high-water threshold. The model predictions were then evaluated based on their ability to identify future high-water events.
